# CRESPO — Niebla Norte (Godot 4)

Puerto jugable del survival 2D a **Godot 4.3**.

## Abrir

1. Instala [Godot 4.3+](https://godotengine.org/download).
2. Importa la carpeta `godot-survival/` (Project → Import).
3. Pulsa **F5** (escena principal: `scenes/main.tscn`).

## Controles

| Tecla | Acción |
|-------|--------|
| WASD | Mover |
| Espacio | Sprint |
| Ratón | Apuntar |
| Clic izq. | Disparar / melee |
| Q | Melee |
| E | Saquear / beber del canal |
| R | Consumir (botiquín / comida / agua) |
| 1–5 | Hotbar de armas |
| T | Ciclar ropa / mochila / luz |
| B | Modo construir |
| Enter | Colocar (barricada / puerta / base) |
| Esc / 0 | Cancelar construcción |

## Contenido

- Ciudad procedural (calles, edificios, canal, farolas)
- Día/noche + clima (lluvia / tormenta)
- Oleadas de zombis
- Inventario, equipo, loot y construcción básica
- Combate melee y armas de fuego

La versión web sigue en `survival/`.
