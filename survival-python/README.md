# CRESPO — Niebla Norte (Python)

Survival zombie top-down en **Python + pygame**.  
Independiente del juego Godot de despachos (`godot/`) y de la versión web (`survival/`).

## Requisitos

```bash
pip install -r requirements.txt
```

## Jugar

```bash
cd survival-python
python3 main.py
```

## Controles

| Tecla | Acción |
|-------|--------|
| WASD / flechas | Mover |
| Espacio | Sprint |
| Ratón | Apuntar |
| Clic izq. | Disparar / melee |
| Q | Melee |
| E | Saquear / beber |
| R | Consumir (med / comida / agua) |
| 1–5 | Hotbar |
| B | Ciclar construcción |
| Enter | Colocar |
| Esc | Salir / cancelar build |

## Contenido

Ciudad procedural, vitals, bate + pistola, zombis, oleadas, loot, día/noche, lluvia, barricadas y base.
