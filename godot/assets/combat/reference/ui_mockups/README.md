# Referencia visual de combate (NO son fondos)

Estos PNG son **mockups de UI** de cómo debe verse la pantalla de combate
(HUD, cartas, poses, atmósfera). **No** deben usarse como `arena` / fondo
de batalla: llevan la interfaz ya dibujada encima del escenario.

- `combat_ui_target_alley.png` — callejón / garaje
- `combat_ui_target_warehouse.png` — almacén / muelle

Usar solo como guía de diseño al pulir combate.
